## 🚀 Deployment Instructions for GitHub Pages

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/shitalparmar443/beauty-parlour-tailoring-stitching.git
   ```
2. Navigate to your project directory:
   ```bash
   cd beauty-parlour-tailoring-stitching
   ```
3. Commit and push your changes:
   ```bash
   git add .
   git commit -m "Update website and documentation"
   git push origin main
   ```
4. Enable GitHub Pages:
   - Go to **Settings** > **Pages** in your GitHub repository.
   - Under **Source**, select **`main` branch** and **`/root` folder**.
   - Click **Save**. Your site will be published at: `https://shitalparmar443.github.io/beauty-parlour-tailoring-stitching/`
